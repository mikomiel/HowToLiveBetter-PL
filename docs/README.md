# Dokumentacja źródłowa upstream

Chińskie teksty i zapisy weryfikacji w tym katalogu pochodzą z HowToLiveBetter. Nie są polskimi poradami ani aktualną wykładnią polskiego prawa. Nie są wczytywane do polskiego czytnika.

Polskie źródła, zakres sprawdzenia, ograniczenia, zmiany i rekordy niepublikowane są bezpośrednio przy [polskich rozdziałach](../book/README.md). [README](../README.md) opisuje pokrycie, metodę i licencje. Nie twórz tu drugiej bazy weryfikacji.
