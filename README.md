## Co pozostało poza czytnikiem

Każda nowa pozycja ma oryginalny numer i decyzję. Nie zmieniamy numeracji, aby zapełnić luki.

- W rozdziale 03 pozycje 9–17, 20–22 i 24 wymagają dalszej weryfikacji. Powody obejmują nieuprawnione uogólnienia, przenoszenie korelacji na interwencję, różne populacje i niezweryfikowane liczby. Pozycje 19 i 25 wymagają polskiej lokalizacji procedur lub informacji o lekach.
- W rozdziale 14 pozycja 5 wymaga pełnej oceny polskich zasad odpowiedzialności za nieautoryzowaną płatność. Pozycja 11 wymaga sprawdzenia polskich procedur i zakresu dostępnych rejestrów. Nie skopiowano chińskich uprawnień ani usług.
- Osiem wcześniejszych wyłączeń rozdziału 04 ma uzasadnienia w jego końcowej tabeli. Nie zmieniono ich na podstawie nowych rozdziałów.

Szczegółowy powód i wymagane dalsze źródła są przy każdym rekordzie. Ich treść nie trafia do wyszukiwania ani kart porad.

## Jak czytać koszty i korzyści

Każda opublikowana porada oddziela koszt pieniędzy, czasu i wysiłku, wynik badań lub treść oficjalnego zalecenia, ocenę redakcyjną opłacalności oraz ograniczenia. Koszty przygotowania są ocenami redakcji, nie pomiarami czasu pracy. Nie podajemy zmyślonych polskich cen. Nie przeliczamy automatycznie czasu na pieniądze lub długość życia.

Mały koszt próby nie oznacza mocnych dowodów. Mocne dowody nie oznaczają opłacalności dla każdego. Kolejność wynika z numerów źródła, nie z rankingu. Nie trzeba wykonywać wszystkich zaleceń.

## Jak czytać dowody

Oznaczenia A/B/C są skrótem redakcyjnym inspirowanym oryginałem, nie formalnym systemem GRADE. Zmianę oznaczenia względem oryginału opisujemy przy poradzie.

| Ocena | Znaczenie w tym wydaniu |
| --- | --- |
| A | Ilościowa synteza badań dotycząca działania i wyniku. Jej projekt, ryzyko błędu i pewność nadal wymagają osobnej oceny. Synteza korelacji nie dowodzi skuteczności porady. |
| B | Pojedyncze badanie, ograniczone próby, przegląd bez jednej wspólnej wielkości efektu lub publikowany wąski wniosek z wytycznych klinicznych. |
| C | Norma prawna, zalecenie operacyjne lub osąd redakcyjny bez bezpośredniego pomiaru skuteczności. Prawo i instrukcja techniczna nie są eksperymentem. |

Litera nie zastępuje opisu źródła. A może dotyczyć syntezy o niskiej pewności, jak w 03.18. C nie oznacza, że norma prawna jest dowolną opinią. Przykładowo d = 0,65 nie oznacza poprawy o 65%, a wzrost z 29,3% do 60,0% wynosi 30,7 punktu procentowego. Nie zamieniamy korelacji w przyczynę ani ilorazu szans w bezwzględne prawdopodobieństwo.

Przy części publikacji dostępny był tylko abstrakt autorów. Przy prawie sprawdzono wskazane artykuły lub oficjalne wyjaśnienia, nie każdą możliwą sprawę. Preprint pozostaje oznaczony jako preprint. Każda porada podaje datę i zakres. Stan verified nie oznacza ponownego wykonania badania, formalnej porady prawnej ani pełnego systematycznego przeglądu najnowszej literatury.

Informacje zdrowotne dotyczą dorosłych w opisanym zakresie i nie zastępują diagnozy ani leczenia. Nie publikujemy dawkowania leków, samodzielnego ograniczania snu ani obietnicy leczenia depresji przez wykonanie listy nawyków. Chińskie kontakty pomocowe zastąpiono sprawdzonym polskim kontaktem tylko tam, gdzie przygotowano pełną poradę. Przy pilnym zagrożeniu nie należy czekać na wykonanie zaleceń produktywności.

## Stan treści i pochodzenie

Kanoniczne porady i rekordy redakcyjne są w trzech plikach [book/pl/](book/README.md). Rejestr CHAPTERS w reader.mjs przechowuje tylko identyfikatory i ścieżki. Czytnik pobiera Markdown, nie osobną bazę ani chińskie rozdziały. Każda porada zawiera oryginalny numer, przypięty odsyłacz do upstream, źródła, projekt dowodu, ograniczenia, datę, zakres oraz opis zmian.

| Stan | Znaczenie |
| --- | --- |
| verified | Sprawdzona kompletna polska porada. Tylko ten stan trafia do czytnika. |
| needs_verification | Rekord oczekuje na potwierdzenie materialnego twierdzenia lub działania. Nie jest gotową poradą. |
| needs_localization | Brakuje sprawdzonego zastosowania w polskich przepisach, instytucjach, rynku lub procedurach. |
| not_applicable | Brak odpowiedniego zastosowania w Polsce. To dostępny stan, niewykorzystany w nowych rozdziałach. |

Chińskie pliki w [book/](book/) i [docs/](docs/), odziedziczony selfcheck.html, skille oraz starsze generatory są **materiałem referencyjnym upstream**, nie gotową polską treścią. Nie są ładowane przez czytnik ani nowe kontrole.

## Uruchom lokalny czytnik

Potrzebujesz Pythona 3 do serwera HTTP. Czytnik nie wymaga instalacji pakietów, konta ani połączeń z usługami zewnętrznymi.

```bash
git clone https://github.com/mikomiel/HowToLiveBetter-PL.git
cd HowToLiveBetter-PL
python3 -m http.server 8000 --bind 127.0.0.1
```

Jeśli sprawdzasz zmiany z niescalonego PR, najpierw przełącz się na jego gałąź. Otwórz http://127.0.0.1:8000/. Nie otwieraj index.html przez file://: przeglądarka może blokować moduł i odczyt treści. Statyczny komunikat wyjaśnia wtedy, jak uruchomić czytnik.

Czytnik ma nawigację rozdziałów, wyszukiwanie we wszystkich opublikowanych poradach, filtr rozdziału i oceny, stałe odsyłacze do porad i rozdziałów oraz szczegóły źródeł. Wyszukiwanie działa także bez polskich znaków. Liczby pochodzą z wczytanych plików. Odsyłacze między rozdziałami działają w Markdown i w czytniku. Obsługuje klawiaturę i małe ekrany.

Zbiór jest pokazywany dopiero po odczycie i sprawdzeniu wszystkich plików. Błąd jednego rozdziału usuwa całość kart i wyświetla wyjaśnienie oraz ponowną próbę. Nie pokazujemy części jako pełnego zbioru. Surowy HTML i niedozwolone adresy w treści nie są wykonywane.

## Jak zgłosić poprawkę

Napisz komentarz do właściwego otwartego PR albo prześlij PR z korektą. Kanał nie wymaga włączania Issues. Podaj identyfikator, kwestionowane zdanie, źródło pierwotne i proponowaną korektę. Nie przesyłaj cudzych danych, haseł ani sekretów. Jeżeli dowodu brakuje, napisz to zamiast dopisywać pewny wniosek.

Przeczytaj [AGENTS.md](AGENTS.md). Edytuj Markdown, nie kopię porady w kodzie. Zmiana materialnego twierdzenia wymaga ponownej oceny i daty. Niezweryfikowana treść pozostaje poza czytnikiem. PR kieruj wyłącznie do main w mikomiel/HowToLiveBetter-PL.

## Kontrole

Potrzebujesz Node.js 22 lub nowszego. Playwright pozostaje jedyną nową zależnością, wyłącznie testową. Czytnik nie ma zależności uruchomieniowych.

```bash
npm ci --ignore-scripts
npm test
npx playwright install chromium
npm run test:browser
```

Testy obejmują wszystkie decyzje źródłowe, stany, pochodzenie, liczby, odsyłacze i workflow. Przeglądarka wczytuje rzeczywiste pliki i sprawdza rozdziały, wyszukiwanie, filtry, klawiaturę, mały ekran i błędy. Chromium z emulacją urządzenia mobilnego nie zastępuje testu fizycznego telefonu, innych silników ani technologii asystujących. Zielony CI nie potwierdza sam naukowej lub prawnej poprawności. Osobny przegląd musi dotyczyć dokładnego opublikowanego HEAD.
