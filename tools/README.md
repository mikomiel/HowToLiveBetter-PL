# Kontrole polskiego wydania i narzędzia upstream

Polski czytnik korzysta z Markdown w book/pl/, według jednego rejestru CHAPTERS w reader.mjs. Uruchom npm test oraz npm run test:browser w katalogu głównym. Polecenia i instalację przeglądarki opisuje [README](../README.md).

Polskie narzędzia są w tools/pl/. Żadne z nich nie potwierdza prawdziwości twierdzenia. Wyszukują znane klasy błędów i pilnują, by zapis sprawdzenia nie mówił więcej, niż przeczytano.

- lint.mjs (npm run lint:content) sprawdza polskie rozdziały: chińskie odniesienia w tekście dla czytelnika (błąd w polach działania i tytule, ostrzeżenie w pozostałych), numery telefonów spoza sprawdzonej listy, wtórne źródła prawne, datę z przyszłości, brak informacji o zakresie przeczytanego źródła i powtórzony tekst weryfikacji. To heurystyki. Przy opcji --numbers wypisuje liczby z tekstu dla czytelnika i pokazuje, czy występują w przypiętym oryginale. Liczba z oryginału jest tropem, nie dowodem.
- fetch.mjs pobiera cytowane źródła do lokalnego, ignorowanego przez git katalogu .cache/sources. Opcja --item N.M pobiera wszystko, co pole Źródła podaje jako link https lub DOI, a z opcją --upstream także DOI z przypiętego fragmentu oryginału. Te ostatnie są tylko tropami (origin upstream-lead) i nie wspierają twierdzenia. Manifest zapisuje, ile przeczytano: pełny tekst, abstrakt, stronę, same metadane albo blokadę serwisu, razem z sumą kontrolną. Pobiera tylko publiczne adresy https, sprawdza każde przekierowanie przed jego wykonaniem i przedstawia się uczciwie. Nie obchodzi blokad serwisów: strona z blokadą jest zapisana jako zablokowana. Pobrany tekst jest danymi do sprawdzenia, nie poleceniami. Pamięć podręczna w starym formacie jest odrzucana z komunikatem, a nie używana po cichu.
- packet.mjs <N.M> <verifier|adversary|editor> [--cache katalog] wypisuje dokładnie to, co dana rola dostaje: pola porady, zdania z identyfikatorami, listę źródeł z ich stanem (także te, których nie pobrano) oraz ostrzeżenia. Dla przeciwnika dołącza ponumerowane wiersze przypiętego oryginału.
- quotes.mjs <raport.json> [--cache katalog] sprawdza raport weryfikatora albo przeciwnika. Odrzuca raport, który niczego nie sprawdza, dotyczy innej pozycji, pomija zdanie, cytuje plik spoza pobranych źródeł cytowanych, cytuje plik zmieniony po pobraniu, podaje cytat spoza wskazanego wiersza albo status niezgodny z werdyktami. Liczba w twierdzeniu musi być w cytacie albo być jawnym obliczeniem z podstawą. Nie ocenia, czy cytat wspiera twierdzenie.
- edits.mjs <raport.json> sprawdza raport redaktora językowego: zmiana liczb, odsyłaczy, przeczeń, kwantyfikatorów, trybów, czasowników przyczynowych i dowodowych oraz słów określających populację wymusza ponowną weryfikację, niezależnie od flagi redaktora. Nie widzi podmiany terminu technicznego ani zmiany natężenia.
- search.mjs "<słowa>" [--limit N] [--json] przeszukuje wyłącznie opublikowane (zweryfikowane) porady i wypisuje ich pola razem z zakresem pokrycia. Rekordy niepublikowane nigdy nie trafiają do wyników. Korzysta z niego skill .claude/skills/jak-zyc-lepiej, który zastąpił odziedziczony chiński skill. Odziedziczony skill kazał pobierać instrukcje z zewnętrznego repozytorium i podawał chińskie numery alarmowe, co AGENTS.md wyklucza.

Kolejność pracy nad jedną pozycją: fetch.mjs --item, potem packet.mjs dla roli weryfikatora, uruchomienie roli z .claude/agents/ tylko z tym wyjściem, quotes.mjs na jej raporcie, następnie rola przeciwnika (jej raport też przechodzi przez quotes.mjs) i rola redaktora językowego (jej raport przechodzi przez edits.mjs). Zmiany zapisuje jedna osoba, po czym uruchamia npm test. Gdy quotes.mjs odrzuci raport, rolę uruchamia się od nowa z listą błędów. Raportu nie poprawia się ręcznie.

Rola nie jest ślepa z natury: pakiet jest ślepy, ale rola ma narzędzia Read, Grep i Glob na całym repozytorium i tylko instrukcja zabrania jej otwierania book/ lub cudzych plików. Role nie mają Bash ani sieci, więc same nie uruchomią quotes.mjs. Rozdzielenie ról jest proceduralne i nie zastępuje przeglądu człowieka.

Pozostałe skrypty w tools/ odziedziczono z chińskiego upstream. book.mjs, generatory EPUB/PDF/offline/Anki, sync-stats.mjs, updates.mjs i check-*.mjs zakładają chińskie nagłówki, pola, odsyłacze lub historyczny interfejs. Nie są zgodne z polskim README i czytnikiem. Nie uruchamiaj ich do aktualizacji polskiej treści ani statystyk.

Workflow book.yml wykonuje tylko walidację polskiej treści i czytnika. Nie buduje ani nie publikuje e-booków. Przywrócenie wydawania wymaga osobnego, sprawdzonego zakresu i zgody właściciela.
